# TTC-Delay-Prediction
# TTC Subway Delay Prediction

Predicting whether a TTC subway delay incident will be long (≥ 5 min)
using historical delay records from Toronto Open Data.

## Research Question
Given when, where and why a subway delay incident happens, can we predict
whether it will cause a delay of 5 minutes or more?

## Data
- Source: Toronto Open Data — TTC Subway Delay Data (January 2025 onward, 45,475 incidents)
- Data is not included in this repo. Download it and place it in `data/raw/`.
